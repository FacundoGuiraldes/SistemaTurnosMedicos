# Anexo - Fundamentos del Diseño Orientado a Objetos

---

El Diseño Orientado a Objetos (DOO) es un paradigma de programación y diseño centrado en la interacción de entidades llamadas objetos, los cuales contienen datos (atributos) y comportamientos (métodos). Este enfoque busca modelar el software organizando el sistema en estructuras lógicas que facilitan la reutilización y el mantenimiento del código. Sus cuatro pilares fundamentales son:

* [Abstracción](./doo-abstraccion.md): Consiste en identificar y modelar únicamente los aspectos esenciales de una entidad para el problema en cuestión, ignorando los detalles irrelevantes.
* [Encapsulamiento](./doo-encapsulamiento.md): Es el proceso de empaquetar datos y métodos dentro de un objeto, ocultando su estado interno y exponiendo solo interfaces públicas seguras.
* [Herencia](./doo-herencia.md): Mecanismo que permite a una clase (subclase) adquirir propiedades y comportamientos de otra (superclase), facilitando la creación de jerarquías lógicas y la reutilización de código (relación de tipo "es un").
* [Polimorfismo](./doo-polimorfismo.md): Capacidad de diferentes objetos de responder de manera distinta y única a un mismo mensaje o llamada a método.
